# The Barber One - TPE Bridge Android
Projet **Android natif** distinct de `salon-queue`, minSdk 24 (Android 7.0+).
Bridge Nepting Concert v3 IP via TCP, serveur de caisse HTTPS, service Android.
**Prototype non valide pour paiements de production.**
Pour compiler: GitHub Actions / Build Android APK ; récupérer l'artifact.
Le bridge Windows et le bridge Android ne doivent pas fonctionner ensemble pour les mêmes paiements.
Impression non prise en charge. Vérifiez chaque transaction sur le terminal avant de réessayer.
